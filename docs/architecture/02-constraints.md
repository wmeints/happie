# Constraints

This section contains the constraints that limit the design of the application.
We've focused only on the technical constraints as this is typically used on
the context of a home.

## Technical constraints

- We must use OAuth authentication flow via the local browser.
- We must use the guidelines offered in [this design document][design_doc], 
  otherwise the interaction with the Albert Heijn API doesn't work.
